1. Project Overview

GeoPulse is a data analytics project focused on understanding retail performance and location-based mobility patterns. The objective is to analyse retail activity, customer footfall, store performance and simulated mobility patterns to generate useful business insights.

I have decided to take responsibility for the complete project development independently, including data collection, data preparation, analysis, validation, dashboard development and final documentation.

6. Dataset Approach

The project will use a suitable retail dataset as its foundation. Additional mobility information, such as simulated hourly visits, location coordinates and dwell time, will be generated separately and clearly labelled as synthetic data.

The final combined dataset will be validated before being used for analysis. Simulated mobility data will not be presented as actual customer movement observations.
